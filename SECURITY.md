# Security Policy

## Supported Versions

We actively provide security patches and improvements for the following versions of **Saasify AI**:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

---

## Reporting a Vulnerability

The safety and privacy of users and contributors is paramount. If you discover a security vulnerability in Saasify AI, please report it responsibly:

1. **Do not create a public GitHub issue** for vulnerabilities that could be exploited in active deployments.
2. Please disclose security concerns by opening a **Private Vulnerability Advisory** via GitHub Security Advisories tab on the repository:
   - Go to [https://github.com/jayshah88/Saasify-AI/security/advisories](https://github.com/jayshah88/Saasify-AI/security/advisories)
   - Click "New draft advisory".
3. Alternatively, contact the maintainer directly via the profile contact options at [https://github.com/jayshah88](https://github.com/jayshah88).

### What to Include in Your Report
- A clear description of the vulnerability.
- Steps to reproduce the issue (proof of concept code or configuration).
- The potential impact and attack vector.
- Any suggested fixes or remediations.

### Response Timeline
- **Initial Response**: Within 48 hours of report submission.
- **Triage & Validation**: Within 5 business days.
- **Remediation & Release**: Critical vulnerabilities will be addressed in a targeted patch release as soon as possible.
