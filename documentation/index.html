Introduction

Welcome to Saasify-AI, the premium HTML template for modern AI startups. Unlike traditional templates, Saasify is built on a modular "Drop-In" architecture that lets you build complex AI interfaces in minutes, not weeks.

Zero Dependencies
Built with Vanilla JS and Tailwind. No React/Vue lock-in.
Modular Features
Copy-paste complex AI components like "Streaming Response" instantly.

Getting Started

We use Vite for a lightning-fast development experience.

1. Install Dependencies

npm install

2. Start Development Server

npm run dev

This will start a local server at http://localhost:5173 with Hot Module Replacement (HMR).

3. Build for Production

npm run build

Generates a production-ready dist/ folder containing pure HTML, CSS, and JS.

Global Theming

Change your brand identity in 2 minutes. Open tailwind.config.js and update the colors:

colors: {
  primary: {
    600: '#4F46E5', // <-- Change this HEX to rebrand buttons/links
    // ...
  },
  slate: {
    950: '#020617', // <-- Change this for background color
  }
}
Note: Dark Mode is enabled by default. The ThemeManager service automatically handles persistence in localStorage.

The "Heist" Library

Saasify includes specialized AI components found in src/components/ai/. These are self-contained modules you can drop into any project.

Omni-Bar

A global command palette triggered by Cmd+K.

// In your main.js
await ComponentLoader.loadAI('omni-bar');

Streaming Response

Simulates an LLM streaming tokens with variable latency. Uses src/core/mock-ai.js.

// Usage
const stream = MockAI.generateResponse('Hello', 'expert');
for await (const chunk of stream) {
    // Update your UI
}

Global Drawers

Standardized slide-in interfaces for User Profiles and Notifications. Triggered via global events.

// Trigger Profile Drawer
window.dispatchEvent(new CustomEvent('saasify:open-profile'));

// Trigger Notification Drawer
window.dispatchEvent(new CustomEvent('saasify:open-notifications'));

Bento Grid

A responsive CSS grid system for dashboards. Located in src/components/base/bento/.

<div class="bento-grid">
  <div class="bento-card col-span-2">...</div>
  <div class="bento-card">...</div>
</div>

Technical Architecture

Deterministic Path Resolution

The template features a unique ComponentLoader that automatically detects its location relative to the project root. This allows you to host the template in subdirectories (like XAMPP's htdocs/project/) or at the root domain without manual path changes.

Global Event Bus

Inter-component communication is handled via src/core/events.js. This allows components to trigger drawers, notifications, or theme changes without being direct children of each other.
