Welcome

Saasify AI - HTML Template

Thank you for purchasing Saasify AI. This template is a premium, high-performance HTML5 UI kit designed for modern SaaS startups, AI tools, and tech products. It is built with Tailwind CSS and Vanilla JavaScript, ensuring zero dependency bloat and maximum customization potential.

Note: This template uses the Tailwind Play CDN by default for immediate preview capabilities. For production use, we strongly recommend following the "Development Build" section to compile your CSS.

Requirements

You can use this template with minimal requirements, or set up a full development environment.

Minimum Requirements

  • A modern text editor (VS Code, Sublime Text, etc.)
  • A modern web browser (Chrome, Firefox, Safari, Edge)

For Development (Optional)

  • Node.js 16.0 or higher (for compiling Tailwind CSS)
  • Terminal / Command Line access

Folder Structure

The package is organized to separate source code, documentation, and build assets.

/
├── css/                  # Directory for compiled CSS output
├── js/
│   └── main.js           # Core JavaScript logic (Vanilla JS)
├── documentation/        # Documentation files (You are here)
├── *.html                # HTML Pages (index.html, pricing.html, etc.)
├── tailwind.config.js    # Tailwind CSS configuration file
├── package.json          # NPM dependencies and scripts
└── README.txt            # Quick start text file

Quick Start (No Code)

If you do not want to use Node.js or compile CSS, you can use the template "as-is".

  1. Unzip the downloaded package.
  2. Navigate to the root folder.
  3. Double-click index.html to open it in your browser.
  4. The template uses a CDN script to load Tailwind CSS, so it will look correct immediately.

Development Build

To customize Tailwind settings or optimize for production, you should use the included build tools.

1. Install Dependencies

Open your terminal in the project root and run:

npm install

2. Start Watch Mode

This will watch your HTML and JS files for changes and rebuild the CSS automatically.

npm run dev

3. Build for Production

This generates a minified CSS file ready for deployment.

npm run build

Colors & Branding

The template uses a centralized color palette defined in tailwind.config.js. You can easily change the primary brand color across the entire site by editing this file.

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#eff6ff',
          500: '#3b82f6', // <--- Change this hex code to your brand color
          600: '#2563eb', // <--- Change this to a slightly darker shade for hover states
          // ...
        }
      }
    }
  }
}

Typography

We use Google Fonts: Inter for body text and Plus Jakarta Sans for headings.

Changing Fonts

  1. Go to fonts.google.com and select your desired font.
  2. Copy the <link> embed code.
  3. Replace the existing font links in the <head> of your HTML files.
  4. Update tailwind.config.js:
fontFamily: {
  sans: ['Your New Font', 'sans-serif'],
  display: ['Your Heading Font', 'sans-serif'],
}

Dark Mode

Dark mode is built-in and enabled by default using the class strategy in Tailwind.

  • Toggle: The theme toggle button in the navbar calls a function in js/main.js.
  • Persistence: The user's preference is saved to localStorage.
  • System Preference: On first load, it checks the user's OS settings (light or dark) if no local preference is found.

To disable dark mode entirely, remove the darkMode: 'class' line from tailwind.config.js and remove the toggle button from the HTML.

JavaScript Behavior

All interactive functionality is contained in js/main.js. It uses pure Vanilla JavaScript with no external dependencies (no jQuery, no Alpine.js, etc.).

Key Functions

initTheme()

Handles light/dark mode toggling and icon switching.

initMobileMenu()

Toggles the visibility of the mobile navigation dropdown.

initPricing()

Listens for the pricing toggle switch and updates price text based on data-monthly and data-yearly attributes.
