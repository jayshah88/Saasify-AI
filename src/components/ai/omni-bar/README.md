# Omni-Bar Component

The nervous system of Saasify-AI. A global command palette for navigation and AI querying.

## Usage
Automatically loaded by `src/main.js`.
Trigger with `Cmd+K` or `Ctrl+K`.

## Files
- `omni-bar.html`: The UI structure.
- `omni-bar.js`: Interaction logic (IIFE).
- `omni-bar.css`: Scrollbar and micro-style overrides.

## Events
- Listen: `saasify:omni-bar-open`, `saasify:omni-bar-close`.
- Emits: `saasify:ai-request`.
